# Previz Studio-v1.6.0

영상 생성에 첨부할 공간 배치, 마네킹 동선, 촬영 구도를 만드는 3D 프리비즈 편집기입니다. 기존 3D 마네킹을 유지하고 입력·편집·프리뷰 흐름을 재설계했습니다.

## 실행

Node.js 22.12 이상. 이 폴더에서 `npm ci`, `npm run dev`를 실행합니다. 기본 주소는 http://127.0.0.1:4173 입니다. 빌드는 `npm run build`, 빌드 프리뷰는 `npm run preview`입니다.

## 기본 흐름

1. 하단 장면 설명을 적고 공간·배우·동작·소품·길이·카메라 선택값을 조정합니다.
2. 장면 구성 버튼으로 선택값에 따른 3D 장면을 만듭니다. 설명 문장은 보조 프롬프트에 저장됩니다. 자유문장 AI 분석은 아직 연결되지 않았습니다.
3. 왼쪽 목록이나 작업 화면에서 배우를 선택해 위치와 동선을 조정합니다. 관련 설정만 오른쪽에 표시됩니다.
4. 오른쪽 촬영 프리뷰에서 실제 출력 구도를 확인합니다. 작업 화면 드래그는 작업 시점 이동이며, 현재 시점으로 촬영 구도 설정을 누르면 실제 카메라에 복사합니다.
5. 촬영 카메라 이동은 기본적으로 샷 전체에 적용합니다. 시작·끝 개별 편집은 상세 설정에서 선택합니다.
6. 영상 내보내기로 MP4를 저장하고 출력 설정에서 PNG와 보조 프롬프트 TXT를 저장합니다.

## 표현 범위

배우 1~4명, 자체 절차적 대기/접근/걷기/달리기, 단순 공간 구조물과 우산/나이프 소품을 지원합니다. 역할 이름은 배우 구별용입니다. 비·밤·재질·외형 설명은 보조 텍스트이며 사실적인 환경 생성이나 모션캡처는 포함하지 않습니다. 기존 규칙 기반 나이프/추격 입력은 명시적으로 선택하는 보조 입력입니다.

WebGL 브라우저를 권장합니다. Canvas 대체 모드는 입체 가림·그림자·소품 표시가 제한됩니다. PNG와 영상은 같은 촬영 카메라/시퀀스 시간 평가를 사용합니다. MP4 인코더를 지원하지 않으면 WebM 대체 또는 오류가 안내됩니다.

## 검증

`npm test`, `npm run check`, `npm run build`를 사용합니다. 실제 브라우저와 영상 검증 결과는 날짜별 전달 기록에 별도 기재합니다. 소스 구조 테스트 통과만으로 사용성을 판단하지 않습니다.

## GitHub / Vercel

별도 v1.6.0-github 폴더 **안의 내용**을 저장소 최상위에 올려 기존 같은 이름 파일과 교체합니다. 폴더 자체를 저장소 하위에 올리지 않습니다. node_modules, dist, 개인 검증 파일은 제외되어 있습니다.

Vercel Framework: Vite. Build Command: npm run build. Output Directory: dist. Root Directory: 저장소 최상위. 배포 후 화면 버전 v1.6.0을 확인하세요. 이번 작업은 로컬 적용이며 GitHub push/Production 배포는 사용자가 수행합니다.

server.mjs는 레거시 테스트 호환용이며 Vite/Vercel 실행에는 사용하지 않습니다. 외부 AI 연결은 없습니다.
