# Previz Studio-v1.5.0

영상 생성 서비스에 첨부할 인물 동선·공간 배치·카메라 레퍼런스를 만드는 3D 프리비즈 도구입니다. 기본 입력은 선택 방식이며 API 키가 필요하지 않습니다.

## 실행

Node.js 22.12 이상. 이 파일이 있는 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:4173 에 접속합니다. `npm run build`는 Vercel용 dist를 만들고 `npm run preview`는 빌드 결과를 확인합니다. 표준 진입점은 index.html → src/app.js입니다.

## 기본 흐름

1. 오른쪽 장면 구성에서 공간, 배우 수·역할, 동작, 움직이는 배우와 접근 대상, 소품 소유자, 길이, 카메라를 선택합니다.
2. 분위기 입력에 비·밤·외형·질감을 적습니다. 이 내용은 보조 프롬프트에 저장되며 3D 날씨 효과를 생성하지 않습니다.
3. 장면 만들기를 누릅니다. 기본 예제는 가게 앞에서 우산을 든 남자에게 여자가 걸어와 멈추는 장면입니다.
4. 배우 동선 편집에서 액션 구간의 출발·도착 X/Z와 시작·끝 시간을 수정합니다. 대기/멈춤 구간은 출발과 도착 좌표를 동일하게 지정합니다.
5. 카메라 프리뷰에서 구도를 확인하고 위치·렌즈·타깃을 조정합니다.
6. MP4/PNG와 영상 생성 보조 프롬프트 TXT를 저장합니다. 영상 생성 서비스에는 레퍼런스 영상과 원하는 분위기 텍스트를 함께 제공합니다.

## 범위

- 배우 1~4명, 색상과 역할 이름으로 구별되는 마네킹.
- 기본 선택 동작: 대기, 다가가기, 걷기, 달리기. 선택한 한 배우의 이동을 기본 구성하고 각 배우의 구간을 수정할 수 있습니다.
- 가게 앞/건물 앞은 출입구가 있는 단순 구조물. 다른 공간은 기존 블로킹 환경.
- 우산/나이프는 선택한 배우 오른손 쪽에 부착. 정교한 파지나 접촉 계산은 없습니다.
- 고정·돌리 인/아웃·오비트, 기존 수동 카메라 편집.
- 동작은 자체 절차적 블로킹이며 실제 모션캡처를 포함하지 않습니다. 정확한 발 접지나 사실적인 무술을 보장하지 않습니다.
- WebGL 권장. Canvas는 간단한 대체 표시이며 정확한 가림·그림자·손 자세가 없습니다.
- 기존 규칙 기반 문장 입력은 별도 모드입니다. 자유 문장 AI 해석은 후속 기능입니다.
- v1.3.5/v1.4.0 씬 문서 검증 호환. 씬 저장과 레퍼런스 명세는 JSON 다운로드입니다.

## 검증

```sh
npm test
npm run check
npm run build
```

기본 장면, 역할/소품 소유자 변경, 여러 인원·공간·카메라, 경로와 시간 연결, 우산 부착을 검증합니다. 브라우저 최종 검증과 출력 정보는 작업 폴더의 전달 기록을 참고하세요.

## GitHub / Vercel

업로드 패키지 **안의 내용**을 저장소 최상위에 올립니다. index.html, package.json, package-lock.json, src, public, vercel.json 등을 기존 같은 이름 파일과 교체합니다. 패키지 디렉터리 자체를 저장소 하위 폴더로 올리지 마세요.

Vercel: Framework Vite, Build Command npm run build, Output Directory dist, Root Directory 저장소 최상위. node_modules/dist/캐시/개인 검증 결과는 업로드하지 않습니다. 배포 후 화면 버전 1.5.0을 확인하세요.

server.mjs는 기존 서버 테스트를 보존한 레거시 파일입니다. Vite/Vercel 실행에는 사용하지 않으며 health 버전은 1.3.5입니다. 외부 AI 요청을 호출하지 않습니다.

자세한 조작은 [사용 설명서](User%20manual.md)를 참고하세요.
