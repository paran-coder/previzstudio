# Previz Studio-v1.4.0

프롬프트에서 지원하는 구문을 분석하여 배우, 기본 동작, 소품, 카메라를 구성하는 3D 프리비즈 편집기입니다. 외부 AI 모델이나 API 키는 사용하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다. 이 파일이 있는 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 배포 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다. 실제 진입점은 `index.html`과 `src/app.js`입니다. 이전 날짜가 붙은 v1.0.1 HTML/서버 파일은 사용하지 않습니다.

## 프롬프트 예시

`마주한 두사람의 나이프액션신. 4초. 카메라는 고정.`

두 배우를 마주 보게 배치하고 나이프 소품과 기본 액션을 구성합니다. 누가 나이프를 갖는지 생략하면 기본 가정을 표시합니다. 고정 카메라 명령은 액션 기본 카메라보다 우선합니다. 띄어쓰기 변형, 1~4명, 마주보기, 추격, 나이프 액션, 고정/오비트/돌리/트래킹 등 지원 표현을 처리합니다.

생성 후 입력창 위에서 해석 결과, 기본 가정과 미지원 안내를 확인하세요. 임의의 모든 자연어 지시를 이해하는 서비스가 아니며 정교한 무술, 접촉 판정, 손가락 파지, 임의 모션 생성은 지원하지 않습니다. WebGL 모드에서 나이프가 손 쪽 팔에 부착되어 움직입니다. Canvas 대체 모드는 나이프 표시를 지원하지 않습니다.

## 검증

```sh
npm test
npm run check
npm run build
```

브라우저 검증은 Microsoft Edge가 설치된 환경에서 다음 미리보기를 실행한 후 다른 터미널에서 수행합니다.

```sh
npm run preview -- --port 4174 --strictPort
node tests/2026-10-04-browser-composition.mjs
```

v1.4.0 로컬 검증: 자동 테스트 41개, 브라우저 점검 16개 통과. 1920×1080, 30fps, 4초 MP4 출력과 디코딩 확인. 실제 Vercel 배포는 업로드 후 별도로 확인해야 합니다.

## GitHub / Vercel

**이 폴더 안의 파일과 하위 폴더를 GitHub 저장소 최상위에 업로드**하세요. `index.html`, `package.json`, `package-lock.json`, `src/` 등이 저장소 최상위에 위치해야 합니다. 릴리스 폴더 자체를 하위 디렉터리로 올리지 마세요. 기존 같은 이름 파일은 이번 파일로 교체합니다.

Vercel 설정은 Framework: Vite, Build Command: `npm run build`, Output Directory: `dist`, Root Directory: 저장소 최상위입니다. `vercel.json`을 포함합니다. 설치된 node_modules, dist, 캐시, 검증 영상은 업로드 대상이 아닙니다. 과거 날짜가 붙은 파일이 저장소에 남아 있어도 현재 Vite 진입점에서는 사용하지 않습니다.

`server.mjs`는 기존 서버 테스트와 호환성 확인용으로 보존한 레거시 파일입니다. Vite/Vercel 실행에는 사용하지 않으며 해당 서버의 health 버전은 기존 1.3.5입니다. 앱 버전은 화면의 1.4.0 표시로 확인하세요.

조작 방법은 [사용 설명서](User%20manual.md)를 참고하세요.
